# RenderDocBread 1.13.136

修复 Bread AI 因单次输出上限而过早结束任务、或最终正文为空的问题。

- API 与 ACP 在同一会话中继续有进展的任务，分段生成大文件；连续空转时
  给出具体状态，保留已完成工作。
- 根据模型上下文预算压缩历史；保留原始任务、精确历史及工具收据供分页
  回读。空白、截断或膨胀摘要不会直接替换有效历史，存档失败不会静默丢证据。
- 超长输入保留完整原文，API、ACP 与 Codex 均可通过既有工具有界读取。
- 截断的工具参数在执行前隔离；恢复过程不重复已完成的工具效果。
- 纯文本分轮续答保留前面各段，避免最终正文只剩最后一段；空续答不会冒充完整回答。
- 修复部分 Codex 版本只在终态快照提供最终回答时，客户端未取到正文的问题。

保留现有模型、推理参数、媒体链路、权限和完整标准版功能。
服务商的模型硬上限、登录、余额及服务可用性仍适用；压缩摘要不保证逐字无损，
关键约束与证据应以保留的原文和收据为准。
