# RenderDocBread 1.13.128 — UE 接入与分层验收工具

本版把 UE 独立分支的编辑连接、资源导入、分层采集与验收工具合入主分支。
这是工具能力发布；UE 效果还原开发仍暂停，尚未完成最终关卡的整体效果验收。

## 已完成

- 按目标 `.uproject` 探测实际安装的 UE5 能力，不要求固定小版本，也不修改引擎源码。
- 公版 Python Editor 提供方支持项目专属常驻连接、后台编辑及跨任务重连；
  可编辑材质、材质函数、实例、蓝图与项目资源，不接管无关 Editor。
- 支持同一捕获多 Draw 导入、可编辑材质资源、灯光诊断变体和浮点分层 RT。
- 区域 HDR 比对支持矩形及有哈希的覆盖掩码、逐通道误差、P95/P99、最大值、
  超差比例、最差像素和分块；显式区域参与判定，保留整图诊断。
- 连续帧验收检查真实输出文件、哈希、尺寸、帧号及时间间隔，报告相邻帧差、
  全序列范围和首尾差；区分静止稳定性与运动变化，识别中途闪烁。
- 材质编译前置检查在诊断 RT 捕获前拦截无有效 Shader 资源、编译失败与默认材质回退。
  同批次按父材质去重编译，后续变体继续检查资源及新增日志。
- 明确 Raw SceneColor 与 Final HDR 的 GI 观察差异，诊断相机记录实际光追选择。
- 保留最新主分支已有改动及对未完成 Mesh/UV 开发的撤回，不重新发布该开发分支。

UE 使用和接口说明见 [UNREAL_RESTORATION.md](../../mcp_host/docs/UNREAL_RESTORATION.md)。
沿用既有 UE 还原规范；本次工具修复没有新增 AI 行为规范或提高效果容差。

## 未完成与验证边界

- 最终 UE 关卡尚未整体验收。局部材质同输入计算通过不代表全角色或最终画面已还原。
- 原生 GI 的风格、空间分布与连续帧稳定性、环境 Cube RT 自动更新及粗糙度 Mip、
  全部实时阴影/环境输入替代仍需继续验证；没有交付“GI 已匹配”的结论。
- 多角度、相机远近、背光、多光源运动、连续帧及最终后处理的完整验收矩阵仍未完成。
  最终材质图可读性、资产依赖及目录清理也未整体通过。
- 连续帧工具验证导出文件和生产者声明的帧元数据，不独立认证真实运行来源；
  可选资产/配置哈希只证明所提供路径的当前状态，不证明全部依赖闭包。
- 编译检查覆盖当前 Editor Shader 平台及消费实例。当前固定接口使用 Bread Python
  提供方；没有该通道时报告能力缺口，不冒充其他平台或原生 MCP 专属会话已通过。
- 实机验证基于安装版 UE 5.5.4 的独立临时工程；其他 UE5 版本及全部 GPU 专项尚未覆盖。
  UE4 暂不属于本工作流。UE Editor、GPU 驱动及用户工程不随程序包分发。

## 配置与交付

- 正式技能及引用文件位于仓库 `.agents/skills`、`replaylab/portable_skills`，
  UE Editor 固定脚本由冻结 Host 一并携带，发布时校验实际文件与源码指纹。
- 标准包保留配置声明的 SDK、工具、许可证与运行依赖；不携带测试工程、RDC、
  私人连接、登录信息、聊天记录或本机测试配置。接收者使用自己的连接与授权。
- 打包在独立目录完成，不替换当前运行中的 Bread 或 UE，不自动恢复暂停的效果任务。
